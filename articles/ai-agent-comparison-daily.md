## 各エージェントの詳細

### ChatGPT (OpenAI)

- **概要:** 最も普及しているLLM。コード実行環境（Advanced Data Analysis）を用いた自立処理や、カスタムGPTを用いた自動化に強み。Deep Researchなどの高度なリサーチ機能も搭載。
- **最新の料金プラン:** 無料 / Go (約1,200円/月) / Plus (約3,000円/月) / Pro (約30,000円/月) 。
  - 無料: 基本的なLLM機能、データ分析などの利用に制限あり。
  - Go: より多くのメッセージ数、高度なデータ分析、長期間のメモリに対応する低価格サブスクリプション。
  - Plus: 最新モデル（GPT-5.3 InstantやGPT-5.2 Thinkingなど）への優先アクセス、高度なデータ分析、より高い利用上限。
  - Pro: 最先端機能への無制限なアクセスや計算リソースの優先割当。
- **主要モデルの特徴:**
  - **GPT-5.3 Instant**: 最速かつ会話のフローが大幅に改善された2026年3月リリースの最新モデル。より正確なWeb検索結果と自然な対話が特徴。直近のアップデートで音声入力時の推論レイテンシが約30%削減され、よりリアルタイムな応答が可能になりました。（★2026-03-10 NEW）（※GPT-4o系統などは順次リタイア）
  - **GPT-5.2 Thinking**: 複雑な推論（Thinkingプロセス）を内包し、高度なコーディングやアルゴリズム開発で絶大な性能を発揮。最大256kトークンの巨大なコンテキストウィンドウ（入力128k/出力128k）に対応。
- **得意なユースケース:**
  - ローカル実行を含む汎用的なコード検証・実行。新たにベータ提供された「Local Sync」機能により、ローカルファイルシステムとの直接的な同期処理も可能になりました。（★2026-03-11 NEW）
  - APIのFunction Callingを活用したエージェント開発
  - Deep Researchを活用した自律的で高度なリサーチ活動
- **関連アプリ・ツール:**
  - **[ChatGPT Projects (Living Sources)](https://openai.com/)**: Google DriveやSlackなどのリンクを貼り付け、外部ソースとシームレスに連携したチーム知識管理が可能。
  - **[Prism](https://openai.com/)**: GPT-5.2を統合した、科学的執筆やコラボレーションのためのAIネイティブな無償ワークスペース。
  - **[Custom GPTs](https://openai.com/chatgpt/custom-gpts)**: 独自の知識や機能を組み込んだ専用エージェントをノーコードで作成可能。
  - **[GitHub Copilot](https://github.com/features/copilot)**: 背後のモデルとしてOpenAIの技術が活用された、最も代表的なコーディングアシスタントアプリ。
  - **[Cursor](https://www.cursor.com/) / [Windsurf](https://codeium.com/windsurf) 等**: API経由で最新モデルを組み込み、エディタ上で直接自動コーディングを可能にする次世代IDE。
- **エンジニア目線の評価:** 開発エコシステムが最も広大で、OpenAI APIはエージェント開発におけるデファクトスタンダードです。2026年のアップデートにより、コンテキストウィンドウの拡大や自律的なリサーチ能力（Deep Research）が追加され、大幅に利便性が向上しています。

### Claude (Anthropic)

- **概要:** 非常に高いコーディング能力とエージェント機能を持つLLM。APIの「Computer Use」を利用し、GUI操作を伴う自律的なタスク遂行が可能。
- **最新の料金プラン:** Web UIは無料 / Pro (約3,000円/月) 。APIは従量課金。
  - 無料: 一部基本モデルの利用（利用上限に達しやすいつくり）。
  - Pro: 最新モデルへの優先アクセス、利用枠の大幅増加、新機能（Artifacts等）の先行利用。
  - API (従量課金): Computer Use等のプログラムからのエージェント制御を利用する場合はこちらが必要。
- **主要モデルの特徴:**
  - **Claude 4.6 Sonnet**: 2026年2月にリリースされた強力なプログラミング能力を持つ主力モデル。100万トークン（ベータ）のコンテキストウィンドウに対応し、エージェントプランニングやデザインなどに優れる。
  - **Claude 4.6 Opus**: 最高レベルの推論やプランニング、デバッグ能力を備える最上位モデル（100万トークン対応）。マルチエージェント（チーム機能）による数時間単位の長期タスク遂行が可能に。
  - **Computer Use機能**: APIを通じて画面のスクリーンショットを読み取り、直接マウスやキーボードの操作コマンドを生成できる。最新のアップデートにより操作精度が向上し、新たなLinux環境等へのネイティブサポートが追加されています。（★2026-03-10 NEW）
- **得意なユースケース:**
  - 100万トークン規模の長文コンテキストの正確な理解
  - セキュアなコード生成とマルチエージェントによる長期タスク遂行
  - PCのオペレーティング自動化（Computer Use）
- **関連アプリ・ツール:**
  - **[Claude Cowork](https://claude.ai/)**: 開発以外の一般ナレッジ分野にもエージェント機能を拡張した、個人やチーム向けの自律的生産性ツール。
  - **[Claude Code (Voice Mode)](https://claude.ai/)**: 音声コマンドだけでローカルエディタ上のコード生成やタスク実行を行える、強力なアプローチのAIコーディング支援。
  - **[Cursor](https://www.cursor.com/) / [Windsurf](https://codeium.com/windsurf)**: エンジニアの必須ツールとなりつつあるAI特化型エディタ。Claude 4.6 Sonnetが相性の良いモデルとして頻繁に利用されます。
  - **[Cline](https://github.com/cline/cline) ([Roo Code](https://github.com/RooVetGit/Roo-Code))**: VSCodeなどのエディタ内で自律的にコードを書いてくれる拡張機能アプリエージェント。特にClaudeとの相性が抜群です。
  - **[v0](https://v0.dev/) / [Bolt.new](https://bolt.new/) / [Lovable](https://lovable.dev/)**: プロンプトから直接WebアプリやUIを生成できるブラウザベースの開発支援アプリ。Claudeの生成能力がこれらを裏側で支えています。
  - **[Artifacts](https://support.anthropic.com/en/articles/9487310-what-are-artifacts)**: Claude公式Web上等でコードを実行・プレビューできる強力な可視化ツール。
- **エンジニア目線の評価:** 3.5 Sonnetのコーディング能力はトップクラスであり、Cursorなどのエディタでもエージェント的なコーディングに最適です。

  - Google AI Pro: 最新・最高性能の Gemini 3.1 Proへのアクセス、Deep Think推論モード、動画生成（Veo 2）など最先端のクリエイティブ・リサーチ機能が利用可能。
- **主要モデルの特徴:**
  - **Gemini 3.1 Pro / 3 Deep Think**: より高度な知性と複雑な問題解決のために開発された最新ハイエンドモデル。特に科学・研究・エンジニアリング向けに特化した推論モード「Deep Think」を搭載しているのが特徴。
  - **Gemini 3.1 Flash-Lite**: Gemini 3シリーズの中でより高速・低コストな実行に特化したマルチモーダルAI。最大100万トークンに対応している。
  - **強み**: Google検索のグラウンディング（事実確認）とシームレスに連携でき、情報の鮮度が高い。直近のアップデートでコンテキストウィンドウが最大400万トークンへ拡張され、長尺動画や巨大リポジトリの解析処理がさらに強化されました。（★2026-03-11 NEW）
- **得意なユースケース:**
  - 大量のリポジトリ全体を読み込ませた解析・処理
  - Deep Thinkモードを用いた複雑な推論・エンジニアリング課題の解決
  - Chrome等Googleエコシステム全体の操作自動化
- **関連アプリ・ツール:**

  - **[NotebookLM](https://notebooklm.google.com/)**: 大量のドキュメントやリソースを理解し、整理・スライド化まで強力にサポートするリサーチワークフローツール。
  - **[Google Project IDX](https://idx.dev/)**: Googleが提供するクラウドベースの次世代ワークスペースエディタ。Geminiが組み込まれアプリ開発までサポートします。
  - **[Android Studio (Gemini in Android Studio)](https://developer.android.com/studio/gemini)**: Androidアプリ開発向けのIDEにAIアシスタントとして直接統合。
  - **[Google Antigravity](https://antigravity.google/)**: Googleが開発するAIファーストの自律型IDEシステム。Gemini 3.1 Pro等を統合し、企画からコーディング・デバッグに至るまでソフトウェア開発の全ライフサイクルをエージェントが自律管理して実行します。
