## 3. 各エージェントの詳細

### ChatGPT (OpenAI)

- **概要:** 最も普及しているLLM。コード実行環境（Advanced Data Analysis）を用いた自立処理や、カスタムGPTを用いた自動化に強み。
- **最新の料金プラン:** 無料 / Plus ($20/月) / Pro ($200/月) 。
  - 無料: 基本的なLLM機能、データ分析などの利用に制限あり。
  - Plus: 最新モデル（GPT-4oなど）への優先アクセス、高度なデータ分析、より高い利用上限。
  - Pro: o1 proモデル等の最先端機能への無制限なアクセスや計算リソースの優先割当。
- **主要モデルの特徴:**
  - **GPT-4o / GPT-4o mini**: 音声・画像・テキストをネイティブに処理するマルチモーダル性を持ち、推論速度が極めて高速。API経由のAgent開発で最も手軽に利用できるスタンダードモデル。
  - **o1 / o3-mini**: 推論（Thinking）プロセスを内包し、複雑なコーディング、アルゴリズム開発、数学的タスクでGPT-4oを大きく上回る性能を発揮。より自立的・論理的なコード理解が得意。
- **得意なユースケース:**
  - ローカル実行を含む汎用的なコード検証
  - APIのFunction Callingを活用したエージェント開発
- **関連アプリ・ツール:**
  - **[Custom GPTs](https://openai.com/chatgpt/custom-gpts)**: 独自の知識や機能を組み込んだ専用エージェントをノーコードで作成可能。
  - **[GitHub Copilot](https://github.com/features/copilot)**: 背後のモデルとしてOpenAIの技術が活用された、最も代表的なコーディングアシスタントアプリ。
  - **[Cursor](https://www.cursor.com/) / [Windsurf](https://codeium.com/windsurf) 等**: API経由でGPT-4o等の最新モデルを組み込み、エディタ上で直接自動コーディングを可能にする次世代IDE。
- **エンジニア目線の評価:** 開発エコシステムが最も広大で、OpenAI APIはエージェント開発におけるデファクトスタンダードです。

### Claude (Anthropic)

- **概要:** 非常で高いコーディング能力を持つLLM。APIの「Computer Use」を利用し、GUI操作を伴う自律的なエージェントとして利用可能。
- **最新の料金プラン:** Web UIは無料 / Pro ($20/月)。APIは従量課金。
  - 無料: Claude 3.5 Sonnet等の基本利用（利用上限に達しやすいつくり）。
  - Pro: 最新モデルへの優先アクセス、利用枠の大幅増加、新機能（Artifactsなど）の先行利用。
  - API (従量課金): Computer Use等のプログラムからのエージェント制御を利用する場合はこちらが必要。
- **主要モデルの特徴:**
  - **Claude 3.5 Sonnet / 3.7 Sonnet**: プログラミング能力において長らく単独トップクラスの評価を得ているモデル。指示への忠実さが非常に高く、リファクタリングやアーキテクチャ設計などの複雑な出力も安定している。
  - **Claude 3.5 Haiku**: Sonnetに準ずる能力を持ちながら推論速度が速く、軽量なエージェントAPI実行に適している。
  - **Computer Use機能**: APIを通じて画面のスクリーンショットを読み取り、直接マウスやキーボードの操作コマンドを生成可能。
- **得意なユースケース:**
  - 長文コンテキストの正確な理解
  - セキュアなコード生成
  - PC操作の自動化
- **関連アプリ・ツール:**
  - **[Cursor](https://www.cursor.com/) / [Windsurf](https://codeium.com/windsurf)**: エンジニアの必須ツールとなりつつあるAI特化型エディタ。Claude 3.5 Sonnetが最も相性の良いモデルとして頻繁に利用されます。
  - **[Cline](https://github.com/cline/cline) ([Roo Code](https://github.com/RooVetGit/Roo-Code))**: VSCodeなどのエディタ内で自律的にコードを書いてくれる拡張機能アプリエージェント。特にClaudeとの相性が抜群です。
  - **[v0](https://v0.dev/) / [Bolt.new](https://bolt.new/) / [Lovable](https://lovable.dev/)**: プロンプトから直接WebアプリやUIを生成できるブラウザベースの開発支援アプリ。Claudeの生成能力がこれらを裏側で支えています。
  - **[Artifacts](https://support.anthropic.com/en/articles/9487310-what-are-artifacts)**: Claude公式Web上等でコードを実行・プレビューできる強力な可視化ツール。
- **エンジニア目線の評価:** 3.5 Sonnetのコーディング能力はトップクラスであり、Cursorなどのエディタでもエージェント的なコーディングに最適です。

### Gemini (Google)

- **概要:** 最大200万トークンのコンテキストウィンドウとマルチモーダル処理ができるGoogleのLLM。
- **最新の料金プラン:** 無料枠あり。Gemini Advanced は月額 ¥3,200。
  - 無料: 基本的なGeminiモデルの利用。
  - Advanced: Gemini 1.5 Proなどの最高性能モデルへのアクセス、200万トークンの巨大コンテキストウィンドウの利用、Google Workspaceとの連携。
- **主要モデルの特徴:**
  - **Gemini 1.5 Pro / 2.0 Pro**: 最大200万という圧倒的なコンテキストウィンドウ（扱えるテキスト長）が最大の特徴。分割なしで大規模リポジトリ全体をそのままプロンプトに乗せる力技が可能。
  - **Gemini 1.5 Flash / 2.0 Flash**: 軽量かつ高速・安価でありながら、Flashでも100万トークンのコンテキストウィンドウに対応。大量ログの処理や検索タスクに最適。
  - **強み**: Google検索のグラウンディング（事実確認）とシームレスに連携でき、情報の鮮度が高い。
- **得意なユースケース:**
  - 大量のリポジトリ全体を読み込ませた解析
  - 動画や大規模ログの処理
- **関連アプリ・ツール:**
  - **[Google Project IDX](https://idx.dev/)**: Googleが提供するクラウドベースの次世代ワークスペースエディタ。Geminiが組み込まれアプリ開発までサポートします。
  - **[Android Studio (Gemini in Android Studio)](https://developer.android.com/studio/gemini)**: Androidアプリ開発向けのIDEにAIアシスタントとして直接統合。
  - **[Google Workspace](https://workspace.google.com/)連携**: ドキュメント、スプレッドシート等と直接連携して動作する公式アプリ連携の強みがあります。
- **エンジニア目線の評価:** 長大なコンテキストを扱えるため、プロジェクト全体をプロンプトで渡し、RAGなしで高度なデバッグをさせることが可能です。また、Google Antigravityのようなツールにより実践的なソフトウェア開発の自動化が劇的に進むと期待されています。

### Devin (Cognition)

- **概要:** Cognition社が開発した自律型AIソフトウェアエンジニア。独自のブラウザやターミナル、エディタを持ち、自己完結で開発タスクを遂行します。
- **最新の料金プラン:** 早期アクセスおよびエンタープライズ向けの個別契約が中心です。
  - 現状: 一般向けの固定公開プランは限定的で、事前登録制（Waitlist）での利用や法人向けの個別契約がメイン。
  - エンタープライズ: SLA保証や高度なセキュリティ要件に応じた専用対応が含まれます。
- **主要モデルの特徴:**
  - 各種最先端のLLM（OpenAIモデル等）をバックエンドで活用し、自律課題解決に特化した独自の推論エンジン（システムプロンプトや環境ツール操作機能）が幾重にも組み込まれていると推測されます。
  - **自律的プランニング**: 渡された仕様書や不正確な指示から「何をすべきか」の計画を立て、エラーが起きたら自分でログを見てコードを修正・再実行するリカバリー能力に特化。
- **得意なユースケース:**
  - エンドツーエンドのアプリケーション開発
  - バグ修正
  - 新しい技術の学習と適応
- **関連アプリ・ツール:**
  - **[Devin Workspace](https://www.cognition.ai/)**: Devinがコマンドやエディタを自律的に操作・実行するための独立したクラウド環境。人間はブラウザアプリのUIからその様子を監視・フィードバックすることができます。
- **エンジニア目線の評価:** 他のエージェントに比べ自律性が圧倒的に高いものの、一部利用ハードルが高いのが難点です。

### CrewAI

- **概要:** ロールベースのAIエージェントを構築するためのフレームワーク。「リサーチャー」「エンジニア」などの役割を持つエージェントをチームとして連携させます。
- **最新の料金プラン:** OSS（無料）。ホスティング・サポート付きのエンタープライズプランあり。
  - OSS版: コストなしで全機能をローカルに構築・実行可能（背後のLLMのAPI利用料は別途）。
  - エンタープライズ版: 本番環境向けのマネージドホスティング、エンタープライズ級のSLA、優先的な技術サポートが提供される。
- **主要モデルの特徴:**
  - フレームワークであるため、背後のLLMは自由に選択・交換可能（OpenAI, Anthropic, ローカルLLM等）。
  - **ロール（役割付け）の再現性**: LLMに対し「シニアエンジニア」「QAテスター」といった強力なペルソナを与え、互いの出力を相互レビューさせるためのプロンプト運用に優れた設計になっている。
- **得意なユースケース:**
  - 複雑なパイプライン処理
  - コンテンツの自動生成
  - 多角的なリサーチ業務
- **関連アプリ・ツール:**
  - **[CrewAI Enterprise](https://www.crewai.com/enterprise)**: CrewAIを社内でスケーラブルに動かし、監視・分析するためのプラットフォーム・ダッシュボードアプリ。
  - **[LangChain](https://www.langchain.com/)関連ツール**: LangChainエコシステムのツール群（[LangSmith](https://smith.langchain.com/)など）と強力に連携し、実行ログのトラッキングアプリと併用されます。
- **エンジニア目線の評価:** LangChainとの連携もスムーズで、タスクの分割と委譲の設計が直感的に行えます。

### OpenHands (旧OpenDevin)

- **概要:** DevinのOSS代替を目指すプロジェクト。最新のLLM（Claude 3.5 Sonnet等）をバックエンドとして利用できます。
- **最新の料金プラン:** 完全無料（オープンソース）。
  - OSS版: Dockerなどを用いて自身のローカル環境に無料で構築可能。
  - ※バックエンドとして利用するLLM（ClaudeやGPT-4 API等）の利用料は、実行した分だけ自身で負担する必要があります。
- **主要モデルの特徴:**
  - バックエンド層としてClaude 3.5 SonnetやGPT-4o系の強力なコーディング対応LLMを利用。
  - **ツール利用能力の拡張**: エージェント自体がコンテナ上で自由にBashやPythonを実行できる環境を与えられており、モデルが本来持つ「コードを考える力」を「環境を操作する力」にマッピングしている。
- **得意なユースケース:**
  - ローカル環境での自動コーディング
  - カスタマイズ可能なエージェント開発
- **関連アプリ・ツール:**
  - **[OpenHands UI](https://github.com/All-Hands-AI/OpenHands)**: ブラウザからエントリポイントとしてアクセスし、AIがターミナルやコードエディタ（Reactベース）を走らせる様子をリアルタイムで監視・操作するための公式Webアプリ。
- **エンジニア目線の評価:** オープンソースで透明性が高く、手元のDocker環境などで安全に実行できる点が魅力です。
